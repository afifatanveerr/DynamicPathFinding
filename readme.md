# Dynamic Pathfinding Agent

This project implements A\* Search and Greedy Best First Search (GBFS)
in a dynamic grid environment with real-time obstacle spawning.

## Features

-   Dynamic Grid Size
-   Random Obstacle Generation
-   Interactive Wall Editing (Mouse Click)
-   A\* and GBFS Algorithms
-   Manhattan and Euclidean Heuristics
-   Dynamic Mode with Re-planning
-   Real-time Metrics (Visited Nodes, Path Cost, Execution Time)

## Requirements

Python 3.x\
Tkinter (comes pre-installed with Python)


``` bash
python dynamic_pathfinding.py
```

## Example input

    Enter rows: 15
    Enter cols: 15
    Obstacle density (0-0.4): 0.2
    Enable Dynamic Mode? (y/n): y
